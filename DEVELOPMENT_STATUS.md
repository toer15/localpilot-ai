# Development status — LocalPilot AI 0.1.5

Last updated: 9 November 2026. Test machine: Windows 11 x64, AMD Ryzen 7 9800X3D, 31.2 GB RAM, AMD Radeon RX 9070 XT 15.9 GB (Vulkan), Node 26.13.0, Ollama 0.40.15, model `qwen3.6:27b` (reports tools, vision and thinking). Release 0.1.5 fixes copying and context overflow. Right-clicking a message now copies it, every message has a Copy action, and the composer/selection get the native edit menu. Oversized turns are truncated head-and-tail, and a provider context rejection triggers one aggressive compaction plus a retry at half `num_ctx` instead of failing the run. Infinite Context adds `infinite.recall`, which searches every archived turn. `npm run typecheck`, `npm run build`, a 15/15 self-test and isolated real-UI copy tests passed. Release 0.1.4 added silent self-installing updates, editable messages and Infinite Context; GitHub Actions run 42664461368 published it after a transient electron-builder download failure.

This document separates **implemented**, **verified**, and **not yet verified**. A build existing is not the same as an installed build being tested.

## Implemented

- Electron + React + TypeScript desktop app with context-isolated preload, typed IPC, dark/light UI, onboarding, chat, streaming, tool cards, approvals, stop, attachments, right workspace panel.
- Local model providers: Ollama (NDJSON, native tools, vision, thinking), OpenAI-compatible SSE (LM Studio, llama.cpp, custom), and a managed llama.cpp engine. The Model library can install the official llama.cpp Windows Vulkan or CPU build without Ollama, download recommended GGUF models with green buttons and quantization choices, import or load local files, and shows cancellable progress for engine installs, model downloads and Ollama pulls. Model discovery, capability reporting/inference and Hugging Face search remain available.
- Chat attachments: file picker, desktop screenshot, and Ctrl+V clipboard-image paste. Image-only messages are allowed; the composer enables Send when an attachment is present even with no text.
- **Full PC access (default on)**: every enabled built-in tool group is exposed regardless of profile group limits, and file read/write/edit/patch/list/search/mkdir/delete/move accept absolute paths anywhere on the PC. High-risk actions still prompt; delete refuses drive roots, Windows, Program Files, ProgramData and the user-profile root. Turning it off restores project-scoped file tools and profile tool-group filtering.
- **Queued follow-up messages**: sending while an agent run is active shows the message above the composer instead of interrupting the run. Queued messages send one at a time after `run_end`; a small × removes one. Stop interrupts only the current run and the next queued message starts afterward.
- **Editable sent messages**: hovering a user turn shows **Edit**. Sending the edited text replaces that message, deletes every message after it, and re-runs the model from that point, so the edited turn becomes the newest turn again. Assistant turns are rejected by the main-process guard. The renderer sends `replaceMessageId`; `chat:send` performs the replace and the rowid-based truncation.
- **Copying messages**: right-clicking a message bubble with no text selected copies the whole message and shows a “Message copied” confirmation; every user and assistant message also has a Copy action. Right-clicking a text selection or the composer opens the native Undo/Cut/Copy/Paste/Select-all menu (the main process only pops that menu for editable fields or a real selection, so the two gestures never conflict).
- **Context overflow recovery**: token estimates are deliberately conservative, a single oversized turn is truncated head-and-tail to fit instead of being sent whole, and if a provider still rejects the prompt with a context/length error the agent compacts aggressively, halves `num_ctx` (never below 8,192), and retries once with a visible notice.
- **Infinite Context plugin (built-in, enabled by default)**: when enabled, older turns removed by context fitting are folded into a merged summary instead of disappearing; `infinite.checkpoint` writes durable plan notes that are re-attached to every request, `infinite.recall` searches every archived turn (nothing is deleted from SQLite) and saved checkpoints, `infinite.status` reports the window/checkpoint state, and the agent iteration and tool-call ceilings are raised to 100,000 steps and 1,000,000 calls. Disabling the pack removes the tools, the summary, and the raised ceilings together.
- Agent: profiles, tool protocol selection, planning loop, per-tool approvals, session approvals, cancellation, emergency stop, activity log, conversation persistence, context fitting to a token budget, one screenshot per iteration, tool-result caps, capability notices. The system prompt now tells local models to operate the PC, use absolute paths when Full PC access is on, use tools for downloads/builds, and name the exact missing setting instead of claiming LocalPilot cannot do the task.
- 60 enabled built-in tools across 13 groups by default; 63 when the optional tester pack is installed. Groups: files, projects, terminal, Git, web, browser, computer, windows, UIA, memory, system, agents, infinite, testing. Tool groups disappear when their built-in pack is disabled or uninstalled.
- Windows Computer Use: PowerShell/C# P/Invoke + UI Automation; screenshots, windows, launch, focus, minimize/maximize/close, mouse, keyboard, UIA inspect/find/click/set value.
- **AI App & Game Tester**: optional marketplace pack with `testing.start`, `testing.stop` and `testing.status`; one DPI-correct click-through overlay window per display, primary-only banner, an independent green AI cursor positioned only by AI mouse/UI Automation targets (it does not follow the user's pointer), takeover border, “Press Esc to stop testing” prompt and global Esc stop. The overlay re-raises itself above topmost full-screen games without focus theft. Uninstalling the pack removes the tools and hides the overlay.
- Browser automation through Playwright Core using installed Edge/Chrome.
- Built-in plugin packs, real MCP SDK stdio/HTTP clients, MCP presets (Roblox Studio, Playwright, Memory, GitHub, Filesystem, Git), native plugin host and example, install/enable/disable/test/uninstall.
- Settings: providers/endpoints/keys (DPAPI), model runtime, agent limits/profiles, Computer Use policy/allowlist/shortcut, Full PC access, global memory, plugins, privacy/local-only, advanced/diagnostics, self-test.
- Persistence: sql.js SQLite under `%APPDATA%\LocalPilot AI\data\localpilot.db`.
- In-app updates: `electron-updater` with the public `toer15/localpilot-ai` GitHub Releases provider. Installed NSIS builds check after startup and every four hours, auto-download, then install silently and restart on their own six seconds after the download completes; an active agent run defers the install in ten-second steps so work is not interrupted. The modal shows download progress and release notes, and **Restart now** installs immediately. Settings → About adds **Check for updates**. `autoInstallOnAppQuit` covers a normal quit, and `latest.yml`, `app-update.yml` and blockmaps are generated by electron-builder. Portable builds do not self-update.
- Packaging: electron-builder NSIS (per-user, x64) and portable, generated icons.

## Known limitations

- **Unsigned builds.** No code-signing certificate is configured. SmartScreen may warn. Updates use public GitHub Releases; portable builds do not self-update. The 0.1.0 → 0.1.1 modal and download were exercised, and preserved copies detected 0.1.2 and 0.1.3 with their release notes; the final NSIS restart/install was not run for those builds. 0.1.4 installs silently and restarts itself, but that handoff was not exercised because no newer packaged release was available during this pass.
- **Full PC access is default-on.** It intentionally bypasses profile tool-group limits and permits absolute file paths outside projects. This is a deliberate capability increase requested for local model operation, not a sandbox. High-risk actions still prompt, and dangerous delete roots are refused, but the test wrote an absolute temporary file rather than exercising destructive deletion outside a project.
- **Installer not exercised.** NSIS packaging succeeded, but no clean-machine install/uninstall, non-admin install, upgrade or uninstall-data-retention test was performed.
- **Two runtimes exercised.** Ollama with `qwen3.6:27b`, and the managed llama.cpp `b12224` engine with Qwen2.5 0.5B Q4_K_M on CPU offload (`gpuLayers: 0`). Vulkan GPU offload, LM Studio, external llama.cpp builds and cloud/OpenAI-compatible providers were not runtime-tested despite being implemented. The managed engine selected its Vulkan build, but this test forced CPU offload.
- **Native plugins are not sandboxed.** They run in a forked Electron child process with IPC but with the user's OS privileges. Manifest permissions are shown to the user but are not enforced by the OS.
- **MCP servers are third-party.** Presets run `npx`/`uvx` servers with user privileges. Local-only mode guards LocalPilot's own providers and internet tools; it cannot contain network access inside an enabled MCP server or native plugin.
- **Capability warnings untested.** The only installed model reports tools/vision/thinking. Warning branches for non-vision attachments or non-thinking reasoning were not exercised.
- **Not tested:** Windows 10, Chrome (Edge was used), actual multi-monitor hardware (only one 2560×1440 display was attached), OS-level per-monitor DPI changes (forced app scale was used instead), screen-reader/keyboard-only use, long-running soak tests, large-project indexing, concurrent agent runs, real Roblox Studio MCP connection, production cloud providers.
- **Browser session reuse.** Playwright uses installed Edge/Chrome; it is not bundled. A missing browser disables those tools' successful operation (the UI does not currently remove them).
- **Local-only definition.** “Local” means a loopback endpoint (`localhost`, `127.0.0.1`, `::1`, `0.0.0.0`). A LAN inference server is treated as non-local and blocked.
- **Installer/test side effects.** Tests wrote real conversations, screenshots and a self-test report to the app data folder. Test-created Notepad was closed without saving changes; its temporary content was not persisted. The overlay test moves the real pointer, exercises the guarded test-only AI mouse action and restores the pointer, then uninstalls the tester pack. The full-screen test launches the installed Rocket League, sends Alt+Enter if needed, and closes only the process it started; the game displayed its own save-failure dialog during the run, which was unrelated to the overlay.
- **Overlay scope.** The green AI cursor is an independent overlay object. It is positioned only by AI mouse and UI Automation target coordinates and stays stationary when the user moves the physical pointer; the real pointer still moves for physical clicks. UI Automation Invoke/Select/Toggle reports the matched element center to the overlay even though those patterns do not move the pointer. The overlay was tested on one 2560×1440 display at 100%, with forced app scales of 125% and 150%, and over Rocket League full-screen. Actual multi-monitor hardware and an OS-level per-monitor scale change were unavailable; forced device-scale-factor is not equivalent to changing Windows display scaling. Only Rocket League was used; other games/engines and other full-screen modes were not tested. Esc is captured globally while the overlay is active, which is intended but prevents the game from receiving Esc during that period. Capture exclusion is requested through Windows; whether a given capture tool honors it is outside LocalPilot's control.
