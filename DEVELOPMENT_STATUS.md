# Development status — LocalPilot AI 0.1.1

Last updated: 9 November 2026. Test machine: Windows 11 x64, AMD Ryzen 7 9800X3D, 31.2 GB RAM, AMD Radeon RX 9070 XT 15.9 GB (Vulkan), Node 26.13.0, Ollama 0.40.15, model `qwen3.6:27b` (reports tools, vision and thinking).

This document separates **implemented**, **verified**, and **not yet verified**. A build existing is not the same as an installed build being tested.

## Implemented

- Electron + React + TypeScript desktop app with context-isolated preload, typed IPC, dark/light UI, onboarding, chat, streaming, tool cards, approvals, stop, attachments, right workspace panel.
- Local model providers: Ollama (NDJSON, native tools, vision, thinking), OpenAI-compatible SSE (LM Studio, llama.cpp, custom), managed llama.cpp launch with GGUF import. Model discovery, capability reporting/inference, Hugging Face GGUF search/download, Ollama pulls.
- Agent: profiles, tool protocol selection, planning loop, per-tool approvals, session approvals, cancellation, emergency stop, activity log, conversation persistence, context fitting to a token budget, one screenshot per iteration, tool-result caps, capability notices.
- 57 enabled built-in tools across 12 groups by default; 60 when the optional tester pack is installed. Groups: files, projects, terminal, Git, web, browser, computer, windows, UIA, memory, system, agents, testing. Tool groups disappear when their built-in pack is disabled or uninstalled.
- Windows Computer Use: PowerShell/C# P/Invoke + UI Automation; screenshots, windows, launch, focus, minimize/maximize/close, mouse, keyboard, UIA inspect/find/click/set value.
- **AI App & Game Tester**: optional marketplace pack with `testing.start`, `testing.stop` and `testing.status`; one DPI-correct click-through overlay window per display, primary-only banner, an independent green AI cursor positioned only by AI mouse/UI Automation targets (it does not follow the user's pointer), takeover border, “Press Esc to stop testing” prompt and global Esc stop. The overlay re-raises itself above topmost full-screen games without focus theft. Uninstalling the pack removes the tools and hides the overlay.
- Browser automation through Playwright Core using installed Edge/Chrome.
- Built-in plugin packs, real MCP SDK stdio/HTTP clients, MCP presets (Roblox Studio, Playwright, Memory, GitHub, Filesystem, Git), native plugin host and example, install/enable/disable/test/uninstall.
- Settings: providers/endpoints/keys (DPAPI), model runtime, agent limits/profiles, Computer Use policy/allowlist/shortcut, global memory, plugins, privacy/local-only, advanced/diagnostics, self-test.
- Persistence: sql.js SQLite under `%APPDATA%\LocalPilot AI\data\localpilot.db`.
- In-app updates: `electron-updater` with the public `toer15/localpilot-ai` GitHub Releases provider. Installed NSIS builds check after startup and every four hours, auto-download, show a global modal when available/downloaded, expose release notes/progress, and install only after explicit **Restart and install**. Settings → About adds **Check for updates**. `latest.yml`, `app-update.yml` and blockmaps are generated by electron-builder. Portable builds do not self-update.
- Packaging: electron-builder NSIS (per-user, x64) and portable, generated icons.

## Known limitations

- **Unsigned builds.** No code-signing certificate is configured. SmartScreen may warn. Updates use public GitHub Releases; portable builds do not self-update. A real version-to-version update install has not yet been exercised.
- **Installer not exercised.** NSIS packaging succeeded, but no clean-machine install/uninstall, non-admin install, upgrade or uninstall-data-retention test was performed.
- **One model/runtime exercised.** Ollama with `qwen3.6:27b` on Windows 11. LM Studio, llama.cpp server, AMD Vulkan llama.cpp offload and cloud/OpenAI-compatible providers were not runtime-tested despite being implemented.
- **Native plugins are not sandboxed.** They run in a forked Electron child process with IPC but with the user's OS privileges. Manifest permissions are shown to the user but are not enforced by the OS.
- **MCP servers are third-party.** Presets run `npx`/`uvx` servers with user privileges. Local-only mode guards LocalPilot's own providers and internet tools; it cannot contain network access inside an enabled MCP server or native plugin.
- **Capability warnings untested.** The only installed model reports tools/vision/thinking. Warning branches for non-vision attachments or non-thinking reasoning were not exercised.
- **Not tested:** Windows 10, Chrome (Edge was used), actual multi-monitor hardware (only one 2560×1440 display was attached), OS-level per-monitor DPI changes (forced app scale was used instead), screen-reader/keyboard-only use, long-running soak tests, large-project indexing, concurrent agent runs, real Roblox Studio MCP connection, production cloud providers.
- **Browser session reuse.** Playwright uses installed Edge/Chrome; it is not bundled. A missing browser disables those tools' successful operation (the UI does not currently remove them).
- **Local-only definition.** “Local” means a loopback endpoint (`localhost`, `127.0.0.1`, `::1`, `0.0.0.0`). A LAN inference server is treated as non-local and blocked.
- **Installer/test side effects.** Tests wrote real conversations, screenshots and a self-test report to the app data folder. Test-created Notepad was closed without saving changes; its temporary content was not persisted. The overlay test moves the real pointer, exercises the guarded test-only AI mouse action and restores the pointer, then uninstalls the tester pack. The full-screen test launches the installed Rocket League, sends Alt+Enter if needed, and closes only the process it started; the game displayed its own save-failure dialog during the run, which was unrelated to the overlay.
- **Overlay scope.** The green AI cursor is an independent overlay object. It is positioned only by AI mouse and UI Automation target coordinates and stays stationary when the user moves the physical pointer; the real pointer still moves for physical clicks. UI Automation Invoke/Select/Toggle reports the matched element center to the overlay even though those patterns do not move the pointer. The overlay was tested on one 2560×1440 display at 100%, with forced app scales of 125% and 150%, and over Rocket League full-screen. Actual multi-monitor hardware and an OS-level per-monitor scale change were unavailable; forced device-scale-factor is not equivalent to changing Windows display scaling. Only Rocket League was used; other games/engines and other full-screen modes were not tested. Esc is captured globally while the overlay is active, which is intended but prevents the game from receiving Esc during that period. Capture exclusion is requested through Windows; whether a given capture tool honors it is outside LocalPilot's control.
